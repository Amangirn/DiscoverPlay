# 🎮 DiscoverPlay

### Discover. Explore. Play.

**DiscoverPlay** is a full-stack game discovery platform designed to help gamers discover new titles, explore different genres, and keep track of the games they love.

Built with a responsive frontend, a Node.js and Express backend, and MongoDB Atlas, DiscoverPlay brings game discovery and personal game management together in one place.

## 🚀 Getting Started

Follow these steps to run DiscoverPlay locally.

**1. Clone the repository**

```bash
git clone https://github.com/Amangirn/DiscoverPlay.git
```

**2. Navigate to the project folder**

```bash
cd DiscoverPlay
```

**3. Install backend dependencies**

```bash
npm install
```

**4. Configure environment variables**

Create a `.env` file in the project root and add the required configuration values.

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
```

Add any other environment variables required by your project.

**5. Start the application**

```bash
npm start
```

_The exact local startup process may depend on your project's scripts and configuration._
